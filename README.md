## 🌟 نبذة عن المشروع والرؤية التربوية

**مشروع رِحْلة (`re7la_Project`)** هو تطبيق ويب تقدمي (Progressive Web App - PWA) صُمم خصيصاً لمساعدة الأطفال في الفئة العمرية المبكرة (3 إلى 5 سنوات) على حب وحفظ سور جزء عم (37 سورة)، بدءاً من قصار السور في بيئة تفاعلية نهارية مشمسة ودافئة كحديقة ربيعية غنّاء.

ينطلق المشروع من بطل صغير ملهم اسمه **"عُمَر"** (3 سنوات)، يصعد طريقاً حجرياً ذهبياً متعرجاً تتوزع عليه محطات السور بين تلال خضراء ومسجد نوراني وشجرة ظليلة، مع ميكانيكا تربوية تحفز الطفل من خلال ربط كل تلاوة بهدية يختارها بنفسه مسبقاً، واحتفال يصدح فيه **صوت والده الحقيقي** تشجيعاً وفخراً.

## 🚫 ميثاق مناهضة الرداءة النمطية (Strict Anti-AI-Slop Covenant)

التزاماً بأعلى معايير الذوق الفني والتربوي، يرفض مشروع رِحْلة القوالب الرقمية المبتذلة:
1. **رفض الأصوات الاصطناعية (Strictly NO AI Voices):**
   - **المرجع القرآني:** المصحف المعلم لفضيلة الشيخ **محمد صديق المنشاوي** مع ترديد الأطفال.
   - **صوت التشجيع:** **صوت الأب أو الأم الحقيقي فقط**، مسجلاً بمشاعر الحب الإنسانية الصادقة.
2. **الوضوح والبهجة النهارية (Daylight Garden):**
   - إلغاء الخلفيات القاتمة والوضع الليلي المعتم للأطفال؛ كل مشهد يفيض بضوء الشمس وزرقة السماء وخضرة التلال.
3. **أزرار ملموسة وطفولية (3D Tactile Controls):**
   - أزرار بارزة ناعمة ثلاثية الأبعاد صُممت لتناسب حركة أصابع الأطفال الغضة دون أخطاء نقر.
4. **صفر مايكروفون أثناء الترديد (Zero-Mic Co-Learning):**
   - التطبيق لا يستمع ولا يسجل صوت الطفل في شاشة الترديد ولا يعتمد على أنظمة التعرف الصوتي الآلية المعقدة أو المحبطة للطفل؛ الطفل يقرأ لوالديه الحاضرين معه في الغرفة، والوالد يتحكم بالجلسة بلمسات ذكية خفية.

## 🏛️ الركائز المعمارية والتقنية (Core Architecture)

### 1. معمارية التخزين المحلي بدون سيرفرات (Local-First PWA)
- **تكلفة استضافة صفرية ($0 Server Cost):** التطبيق يعمل بالكامل كملفات ثابتة (Static Client-Side App) جاهزة للرفع على GitHub Pages أو Cloudflare Pages أو Vercel.
- **أمان وخصوصية مطلقة (100% Child Privacy):** لا توجد أي قاعدة بيانات مركزية ولا تخرج أي صورة أو تسجيل صوتي خارج هاتف العائلة.
- **تسجيل صوت الأب والأم:** يُسجل المقطع من شاشة الإعدادات ويُحفظ كـ `Blob` داخل **`IndexedDB`** محلياً.
- **تركيب صورة وجه الطفل:** تُدمج صورة الطفل على جسم الأفاتار محلياً عبر `HTML5 Canvas` وتُحفظ داخل `IndexedDB`.
- **تشغيل بدون إنترنت (100% Offline):** التطبيق يعمل حتى في وضع الطيران وأثناء السفر.

### 2. ميكانيكا الترديد التربوية (Pedagogical Mechanics)
- **الخطاف الذهبي (The Golden Hook):** يختار الطفل هديته المرتقبة (سيارة سباق، حيوان لطيف، طائرة) **قبل التلاوة**، وتُوضع في صندوق كنز مغلق بقفل ذهبي يرافقه في شاشة الترديد ليهتز حماساً مع كل آية.
- **لعبة الصوت الغائب (Audio Peek-a-boo):** الشيخ المنشاوي يتلو الآية، ثم يسكت التطبيق في وقفة صمت مدروسة ليردد الطفل.
- **اللمسة الخفية (Invisible Tap):** يلمس الوالد الشاشة في أي موضع خلسة لإيقاف التلاوة أو إعادة الآية دون أن يشعر الطفل بوجود قيود تحكم.

## 📱 رحلة الطفل عبر الشاشات الست المعتمدة (The 6-Screen Journey)

```
[ الشاشة 1: خريطة طريق الحفظ ] ──(انطلق في المسار)──> [ الشاشة 2: مسار السور (جزء عم) ]
          │                                                       │
          │ (إعدادات الوالد)                                      │ (اختر السورة)
          ▼                                                       ▼
[ الشاشة 4: إعدادات اللعب والأهل ] <──(إغلاق وعودة)── [ الشاشة 3: اختيار الهدية المرتقبة ]
          │                                                       │
          │                                                       │ (قفل الهدية وابدأ)
          │                                                       ▼
          └─────────── (خروج آمن) ───────────< [ الشاشة 5: الترديد النشط (سورة الفلق) ]
                                                                  │
                                                                  │ (اكتمال الآيات)
                                                                  ▼
[ الشاشة 2: مسار السور ] <──────(سورة جديدة)─────── [ الشاشة 6: الاحتفال وصوت الأب ]
```

### 1. الشاشة 1: خريطة "طريق رحلة حفظ القرآن" (Winding Garden Road)
- تلال خضراء مشمسة، سماء زرقاء صافية، مسجد القبة الخضراء التركوازية على اليسار، شجرة وارفة على اليمين.
- طريق حجري ذهبي متعرج يصعد للأعلى حاملاً محطات السور: سورة الناس (مكتملة ✓)، سورة الفلق (المحطة الحالية 🌟 حيث يقف البطل عمر بمصحفه الأخضر).
- لافتة خشبية لطيفة في الأسفل: *"كل يوم آية جديدة ❤️"*.
- شريط البطل العلوي: صورة عمر، رتبة "مستكشف صغير"، إنجاز "جزء عم: 1/30"، وزر الإعدادات.

### 2. الشاشة 2: مسار اختيار السورة والتقدم (Surah Milestones)
- مسار سور جزء عم الـ 37 بالترتيب التنازلي التوقيفي الشريف.
- كروت بيضاء ناصعة للسور تبرز سورة الفلق الحالية باللون الذهبي البهيج.
- أوسمة النجوم للسور المكتملة وعرض رصيد إنجازات الطفل.

### 3. الشاشة 3: اختيار الهدية المرتقبة | الخطاف الذهبي (The Golden Hook)
- تحفيز مسبق للطفل عبر تبويبات الهدايا: سيارات سباق 🏎️، حيوانات أليفة 🦁، طائرات ✈️، ألغاز 🧩.
- كارت ثلاثي الأبعاد لسيارة السباق الحمراء مع قفزات مرحة.
- صندوق الكنز الخشبي المقفل بقفل ذهبي مبتسم `📦🔒`.
- زر: *"ضع الهدية في الصندوق وابدأ! 🔒✨"*.

### 4. الشاشة 4: نافذة إعدادات اللعب وصوت الأهل (Settings & Parent Voice Modal)
- كارت أبيض ناعم عائم فوق الحديقة المشمسة، وعمر يجلس بلطف على حافته العلوية.
- اختيار الأفاتار ورفع صورة وجه الطفل الحقيقي لحفظها في `IndexedDB`.
- زر تسجيل صوت الأب الحقيقي للتشجيع والاحتفال وحفظه في `IndexedDB`.
- أزرار دائرية لتكرار الآية: `[ 1 ]` `[ 2 ]` `[ 3 ]` `[ 4 ]` `[ 5 ]`.
- مفتاح للتشغيل التلقائي للآيات وراء بعضها بدون لمس.
- مسألة جمع عشوائية لحماية الإعدادات (Math Gate: `8 + 5 = 13`).

### 5. الشاشة 5: شاشة الترديد النشط لسورة الفلق مع المنشاوي المعلم (Active Recitation)
- عمر يقف تحت الشجرة الكبيرة ممسكاً بمصحفه الأخضر.
- دوائر الآيات الخمس في الأعلى `(1)` `(2)` `(3)` `(4)` `(5)`، الدائرة الحالية تضيء باللون الأصفر الذهبي المشمس.
- كارت الآية المركزي الثلجي الفاخر: **﴿ قُلْ أَعُوذُ بِرَبِّ الْفَلَقِ ﴾** بخط أميري واضح جداً.
- أزرار التلاوة: `[ الشيخ والأطفال (المصحف المعلم) ]`، `[ الشيخ فقط ]`، و `[ تخطي الآية ]`.
- ميكانيكا لعبة الصوت الغائب والموجات الصوتية التفاعلية مع صندوق الكنز المغلق الذي يهتز شوقاً للفتح.

### 6. الشاشة 6: شاشة الاحتفال وفتح الكنز مع صوت الأب (Celebration & Unboxing)
- انفتاح غطاء الصندوق `📦🔓✨` وانطلاق سيارة السباق لتدور في حديقة الحفظ.
- تساقط القصاصات الملونة (Confetti) مع أنوار ذهبية مبهرة.
- انطلاق **صوت الأب الحقيقي المسجل** فوراً:
  > *"عاش يا بطل يا عُمر! أنا فخور بيك يا حبيبي ومبارك حفظ سورة الفلق!"*
- منح وسام حافظ سورة الفلق وأزرار: اللعب بالهدية، الانتقال للسورة التالية، وإعادة التلاوة للتثبيت.

## 🧪 أداة الفحص والتحقق الآلية (Automated Verification Suite)

يحتوي المستودع على سكريبت فحص شامل ودقيق: `verify_diagram.py`:
- يتحقق من سلامة وجود وتكامل كافة الملفات.
- يضمن تفعيل اتجاه اليمين لليسار (RTL) وخطوط الخط العربي الشريف (Cairo, Tajawal, Amiri).
- يتأكد من وجود الشاشات الست في مخطط الـ SVG ومحاكي الهواتف.
- يتحقق من اكتمال مسارات التوجيه الـ 13 ومحرك التحريك والتكبير (Pan & Zoom Engine).
- يفرض الصرامة التامة لميثاق صفر مايكروفون أثناء الترديد.
- يفحص سلامة كود JavaScript عبر مترجم Node.js مباشرة (`node -c`).

لتشغيل الفحص:
```bash
python verify_diagram.py
```

## 🚀 طريقة التشغيل والمساهمة (Getting Started)

### متطلبات التشغيل:
- متصفح ويب حديث (Chrome, Edge, Safari, Firefox).
- Python 3.9+ (لتشغيل سكريبتات التوليد والفحص).
- Node.js (اختياري - للتحقق من سلامة كود الـ JS).

### خطوات التشغيل:
1. استنساخ المستودع:
   ```bash
   git clone https://github.com/<your-username>/re7la_Project.git
   cd re7la_Project
   ```
2. فتح المخطط التفاعلي مباشرة في المتصفح:
   - قم بالنقر المزدوج على `app_flow_diagram.html`.
3. لتوليد المخطط من السورس كود:
   ```bash
   python generate_app_flow.py
   ```
4. لتشغيل جناح الاختبارات:
   ```bash
   python verify_diagram.py
   ```
